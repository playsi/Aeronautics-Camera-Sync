# Sable Camera Sync
Adds dynamic camera rotation synced with moving contraptions from [Sable](https://modrinth.com/mod/sable)

## Description
**Sable Camera Sync** enhances immersion by synchronizing the player’s camera with the rotation of moving contraptions.

When standing on ships or other dynamic structures from Sable, your view will smoothly rotate along with the contraption instead of staying fixed to the world. This makes movement feel more natural, especially during turns, tilts, and aerial maneuvers.

### ⚠️ **Requires Sable and all its dependencies**

## Notes
- Works only when standing on moving contraptions
- Intended for visual immersion — does not affect gameplay mechanics
